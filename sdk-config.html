快速開始：3 步驟嵌入

1

註冊網站並取得 Site ID

在下方表單輸入網站資訊，系統會自動產生唯一的 Site ID。

2

選擇啟用的 AI Agent

預設啟用全部 6 大 Agent，也可依需求勾選。

3

複製嵌入代碼

將以下代碼貼到網站的 </body> 前。

<!-- SNT Nexus SDK - 六大 AI Agent 自動對接 -->
<script src="https://xingdeng.tw/sdk/snt-nexus-sdk.js"
data-site-id="your-site-id"
data-agents="AI-00,AI-01,AI-02,AI-03,AI-04,AI-05"
data-theme="dark"
data-position="bottom-right"
></script>
自動偵測：SDK 會根據使用者訊息自動選擇最適合的 AI Agent 回應。
內建分析：自動追蹤頁面瀏覽、互動次數、轉換率等數據。
響應式設計：聊天小工具自動適配手機/平板/桌面。
3

已註冊網站

共 0 個網站
尚無已註冊網站，請在上方表單註冊
4

SDK API 文件

手動初始化（進階用法）

// 載入 SDK
<script src="https://xingdeng.tw/sdk/snt-nexus-sdk.js"></script>

// 手動初始化
<script>
  window.SNT.init({
    siteId: 'your-site-id',
    agents: ['AI-00', 'AI-01', 'AI-02'], // 只啟用部分 Agent
    theme: 'dark',
    position: 'bottom-right',
    autoDetect: true,
    analytics: true,
    chatEnabled: true,
    leadCapture: true
  });
</script>

公開 API 方法

// 切換聊天面板
window.SNT.toggleChat();

// 選擇特定 Agent
window.SNT.selectAgent('AI-01');

// 取得目前 Agent
const agent = window.SNT.getCurrentAgent();

// 取得分析數據
const stats = window.SNT.getAnalytics();
console.log(stats); // { pageViews: 5, interactions: 12, conversions: 2 }
